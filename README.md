Restaurant Daily Sales Register

This project focuses on analyzing restaurant daily sales data using Microsoft Excel.

Objectives
- Analyze daily sales performance.
- Track sales target achievement.
- Analyze payment methods and top-selling items.
- Generate insights using Pivot Tables and charts.

Tools Used
- Microsoft Excel
- Excel Formulas
- Pivot Tables
- Charts and Conditional Formatting

Project File
- Excel workbook containing the sales register and analysis.
